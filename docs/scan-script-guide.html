ScanScript Guide

How to write pattern scripts for full ASX universe scans · ASX Sector Intelligence

ScanScript is the desk’s text language for defining My Patterns. You write simple rules in a text box; the app compiles them into scanner conditions and runs them across every ASX stock — no TradingView Pine, no webhooks, no code execution.

1. Quick start — create a pattern in the app

  1. Open any stock chart (or the main desk) and open the Pattern Analysis panel on the right.
  2. Under Create my pattern, click New.
  3. Enter a pattern name, choose Bullish / Bearish / Neutral, and optional notes.
  4. Under How to detect, select ScanScript (text rules).
  5. Type your script in the text area. Red errors appear if syntax is wrong; a green Compiles to… line shows the parsed rules.
  6. Click Save private pattern. The scanner runs on charts and on the full industry scan.

2. Script structure

A script is plain text, one statement per line. Empty lines and lines starting with # are ignored.

# Oversold with volume — example header comments
bias bullish
match all

rsi(14) <= 35
rvol >= 1.5
above_sma(50)

Optional headers

LineMeaning
match allEvery condition must be true (AND). Default if omitted.
match anyAt least one condition must be true (OR).
bias bullishSets pattern bias to bullish (overrides the form dropdown).
bias bearishSets pattern bias to bearish.
bias neutralSets pattern bias to neutral.

Headers accept an optional colon: match: all and bias: bullish also work.

3. Conditions reference

Each condition line compares a metric to a number using >, >=, <, <= (Unicode ≥ / ≤ also accepted).

RSI

rsi(14) <= 30
rsi(14) >= 70

14-period RSI on daily closes. Range 0–100. Only period 14 is supported. Aliases: rsi14.

Relative volume (RVOL)

rvol >= 1.5
relative_volume >= 2

Today’s volume divided by the average of the previous 20 sessions. 1.5 = 50% above average. Aliases: relative_volume, rel_volume.

Percent above moving averages

above_sma(50)
below_sma(200)
above_ema(21)
below_ema(21)

Shorthand: above_sma(50) means close is above the 50-day SMA (≥ 0% above). below_sma(50) means below (< 0%).

With explicit threshold:

above_sma(50) >= 2    # at least 2% above 50 SMA
below_sma(20) <= -3   # at least 3% below 20 SMA
FunctionPeriodsMeaning
above_sma(n) / below_sma(n)20, 50, 200% distance of close from SMA
above_ema(n) / below_ema(n)21 only% distance of close from EMA

Negative values mean price is below the average (e.g. -2 = 2% below).

Percent change

pct_chg(5) >= 5
pct_chg(20) >= 10
pct_change(5d) >= 3

Percentage change over 5 or 20 trading days. Aliases: pct_change, change. Optional d suffix on the argument (5d).

4. Limits and behaviour

TopicDetail
Max conditions8 per script (form UI allows 4; ScanScript allows more).
LookbackA hit fires if conditions are true on any of the last ~10 daily bars within your scan window.
Scan windowUse Pattern panel buttons (e.g. 1M, 3M, 6M) — only hits whose start date falls in that window count.
DataDaily OHLC from Yahoo. Stocks without data are skipped (same as other scanners).
SecurityScripts compile to fixed metrics only — no loops, functions, or arbitrary code.

5. Example scripts

Oversold bounce (bullish)

bias bullish
match all

rsi(14) <= 35
rvol >= 1.5
above_sma(200)

RSI oversold, elevated volume, still above long-term trend.

Stage-style trend (bullish)

match all

above_sma(50)
above_sma(200)
pct_chg(20) >= 8
rsi(14) >= 45
rsi(14) <= 75

Above 50 and 200 SMA, 20-day momentum, RSI not extended.

Volume breakout

match all

rvol >= 2
pct_chg(5) >= 3
above_sma(20)

Bearish weakness

bias bearish
match all

rsi(14) >= 70
below_sma(50)
pct_chg(5) <= -3

Flexible filter (OR)

match any

rsi(14) <= 30
rsi(14) >= 70

Flags either oversold or overbought extremes.

6. Where results appear

  • Chart modal — Pattern Analysis → My Patterns category shows hits for the open stock.
  • Sector Table — My Pattern hits appear as chips on each stock row (labelled with your pattern name).
  • Industry scan — Background scan evaluates all tickers when OHLC is loaded; results are cached locally.

My Patterns are private (stored in your browser). They are separate from Special Patterns (✦) and starred chart patterns (★).

7. Troubleshooting

Error / issueFix
invalid syntaxCheck operators and parentheses. One condition per line.
Add at least one conditionScript has only headers/comments — add metric lines.
max 8 conditionsSplit into two patterns or simplify rules.
pct_chg supports 5 or 20Use pct_chg(5) or pct_chg(20) only.
No hits on deskWiden scan window; confirm Yahoo data exists for tickers; conditions may be too strict.
Save button disabledFix red validation errors in the script editor first.
